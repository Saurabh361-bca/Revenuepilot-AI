# RevenuePilot AI — Intelligent Sales & Revenue Operations

**Team:** Skmehracse
**Author:** Saurabh Kumar Mehra

## Problem

Sales teams lose revenue due to poor lead prioritization and lack of follow-ups.

## Solution

RevenuePilot AI is a multi-agent system that:

* Detects risky deals
* Generates outreach
* Predicts churn

## Tech Stack

* Node.js
* Express
* HTML UI

## Run

npm install
node backend/index.js

Open: http://localhost:3000/run-agents

## Impact

+20% conversion
-15% churn
₹1.75L revenue improvement
